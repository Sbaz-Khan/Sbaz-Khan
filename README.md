## Featured Projects

### [CNES Cloud Chamber Control PCB](https://github.com/Sbaz-Khan/CNES-Cloud-Chamber-Control-PCB)
Ongoing **ESP32-based control PCB** for the Concordia Nuclear Engineering Society's portable diffusion cloud chamber. Designed in KiCad with thermistor sensing, MOSFET load control, PCB-mounted OLED/buttons, auxiliary power distribution, and interfaces for electronic Peltier power adjustment.

### [DC Microgrid Modeling & Control](https://github.com/Sbaz-Khan/Dc-Microgrid-Research)
Ongoing **MATLAB/Simulink and Simscape Electrical** project focused on DC microgrid modeling, renewable-energy integration, power electronics, **P&O MPPT**, battery storage, bidirectional DC-DC conversion, and closed-loop DC bus voltage regulation.

### [STM32F103 Custom Development Board](https://github.com/Sbaz-Khan/STM32F103-Custom-Development-Board-PCB)
Designed a **two-layer STM32F103 development board in KiCad**, covering schematic capture, USB, SWD, UART, I²C, power regulation, decoupling, PCB layout, differential-pair routing, DRC, BOM preparation, and manufacturing files.

### [SeatFindr — Smart Occupancy Monitoring](https://github.com/Sbaz-Khan/SeatFindr-Occupancy-Monitoring)
IoT-based study-space occupancy monitoring system combining an **HLK-LD2450 mmWave radar sensor, ESP32, Firebase Realtime Database, and Android application**. My primary contributions included Android UI development, smart search, room sorting/filtering, Firebase integration, sensor testing, and end-to-end system integration.

### [Autonomous Hovercraft](https://github.com/Sbaz-Khan/Autonomous_Hovercraft)
Early undergraduate team project involving an Arduino-based autonomous hovercraft. My contribution focused primarily on **physical construction, hardware integration, sensor calibration, weight distribution, testing, and troubleshooting**.
